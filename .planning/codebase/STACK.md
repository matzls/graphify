## Configuration

**Environment:**
- `GRAPHIFY_OUT` changes output/cache directory names in `graphify/__main__.py`, `graphify/cache.py`, and `graphify/watch.py`.
- `GRAPHIFY_FORCE` allows forced graph writes/rebuilds in `graphify/__main__.py` and `graphify/hooks.py`.
- `GRAPHIFY_VIZ_NODE_LIMIT` controls HTML visualization size guard in `graphify/export.py`.
- `GRAPHIFY_GOOGLE_WORKSPACE` enables Google Workspace shortcut export in `graphify/google_workspace.py`; `GRAPHIFY_GOOGLE_WORKSPACE_TIMEOUT` controls `gws` export timeout.
- `GRAPHIFY_WHISPER_MODEL` and `GRAPHIFY_WHISPER_PROMPT` tune local transcription in `graphify/transcribe.py`.
- `GRAPHIFY_MAX_OUTPUT_TOKENS`, `GRAPHIFY_LLM_TIMEOUT_SECONDS`, `GRAPHIFY_FILE_CHAR_CAP`, and `GRAPHIFY_SEMANTIC_TOKEN_BUDGET` tune semantic extraction in `graphify/llm.py`.
- AI backend keys/model overrides are read in `graphify/llm.py`: `GEMINI_API_KEY`, `GOOGLE_API_KEY`, `MOONSHOT_API_KEY`, `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, `OLLAMA_BASE_URL`, `OLLAMA_MODEL`, `OLLAMA_API_KEY`, `GRAPHIFY_OLLAMA_MODEL`, `GRAPHIFY_GEMINI_MODEL`, `GRAPHIFY_OPENAI_MODEL`, `GRAPHIFY_BEDROCK_MODEL`, `AWS_PROFILE`, `AWS_REGION`, and `AWS_DEFAULT_REGION`.
- `NEO4J_PASSWORD` is preferred over CLI password arguments for Neo4j export in `graphify/__main__.py`.
- No `.env` files were detected in the repo scan.
